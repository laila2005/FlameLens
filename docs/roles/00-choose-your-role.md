# Choose your role / اختر دورك

English first, then Arabic below. / الإنجليزية أولًا ثم العربية بالأسفل.

## English

Pick the role that fits your experience. You do **not** need to know everything on the list. "Required" means you must be comfortable with it on day one. "Learn in 2 days" means you can pick it up before the hackathon with the practice tasks in your role file.

| Role | Required (must have) | Nice to have | Learn in 2 days | You will enjoy it if you like | Coding? |
|---|---|---|---|---|---|
| **A. Tech lead and backend** ([tasks](A-tech-lead-backend.md)) | Python you can write and test, git and pull requests, basic REST APIs | FastAPI or Flask, SQL, Docker, deploying an app | FastAPI basics, Render or Fly deploy | Making decisions, unblocking people, keeping things running | Heavy |
| **B. Frontend lead** ([tasks](B-frontend.md)) | React and TypeScript basics, HTML and CSS, calling an API with `fetch` | Tailwind, Vite, responsive design, Figma, accessibility | Tailwind, Plotly in React | Making things look clear and polished | Heavy |
| **C. Charts and lenses** ([tasks](C-charts-lenses.md)) | Any data-visualisation library (Plotly, Matplotlib, D3, Chart.js), comfortable with axes and units | React, geometry (distances, circles), numerical thinking | Plotly.js basics | Turning numbers into pictures that explain | Medium to heavy |
| **D. Data extractor - Judy** ([tasks](D-data.md)) | Spreadsheets (Excel or Google Sheets), reading English scientific papers and PDFs, attention to detail, unit conversion | Science or engineering background, Python with pandas, reading charts | The row format and extraction rules | Careful, detailed work where accuracy matters | Light (none required) |
| **E. AI and retrieval** ([tasks](E-ai-retrieval.md)) | Python, JSON, calling APIs | Prompting or LLM experience, Ollama or Hugging Face, embeddings, testing mindset | Ollama basics, simple retrieval | Making AI behave reliably and safely | Heavy |
| **F. Research, docs, pitch and QA** ([tasks](F-research-pitch-qa.md)) | Clear writing and speaking (Arabic and English), organised, curious | Presenting or pitching, video editing, slides or Figma, testing experience | Reading research papers, the QA plan | Telling the story, checking facts, finding bugs | None |

### How to choose (5 minutes)

1. Read the table. Circle the roles where you meet **every** "Required" item.
2. If you circled more than one, pick the one where you have the most "Nice to have" items, or the one you want to learn.
3. If you circled none, choose D or F. They need care and curiosity, not code. You can grow into a programming role later.
4. Post your first and second choice in the chat. Ties go to whoever has built something similar before.
5. Write your name and a **backup** in [../02-team-roles.md](../02-team-roles.md).

### Quick self-check

Answer yes or no. Count the yes answers in each group.

- **Group A/E (backend and AI):** I have written a Python program of 100+ lines. I know what JSON is. I have used an API. I have used git.
- **Group B/C (frontend and charts):** I have built a web page with buttons or a form. I have drawn a chart with code. I like fixing how things look.
- **Group D/F (data and research):** I enjoy reading long documents. I notice small mistakes. I can explain an idea simply in front of people. I like organising.

Mostly yes in a group: choose a role from that group.

### If the team does not match perfectly

| Situation | What to do |
|---|---|
| Only 3 strong programmers | A, B, E code. C's tasks split: charts go to B, the Evidence-case logic to A. Drop Lens 3 early |
| 4 strong programmers | A, B, C, E as planned. F and D do not need to code |
| Nobody has done data science | D and F work in a shared sheet. C and A write the loader so nobody needs pandas |
| Nobody has used an LLM | E practises with Ollama in Task E1 and E5. The AI is optional in our design, the app works without it |
| Nobody is good at design | B copies the existing mockup. It is already designed |

## العربية

اختر الدور الذي يناسب خبرتك. **لا** تحتاج أن تعرف كل ما في القائمة. "مطلوب" يعني أنك يجب أن تكون مرتاحًا معه من اليوم الأول. "تتعلمه خلال يومين" يعني أنك تستطيع تعلمه قبل الهاكاثون من خلال المهام التدريبية في ملف دورك.

| الدور | مطلوب (يجب أن يتوفر) | ميزة إضافية | تتعلمه خلال يومين | ستستمتع به إذا كنت تحب | برمجة؟ |
|---|---|---|---|---|---|
| **A. قائد تقني وBackend** ([المهام](ar/A-tech-lead-backend.md)) | Python تكتب به وتختبره، git وPull Requests، فهم أساسي لـ REST APIs | FastAPI أو Flask، SQL، Docker، نشر تطبيق | أساسيات FastAPI، النشر على Render أو Fly | اتخاذ القرارات، مساعدة الفريق، إبقاء كل شيء شغالًا | كثيرة |
| **B. قائد الواجهة (Frontend)** ([المهام](ar/B-frontend.md)) | أساسيات React وTypeScript، HTML وCSS، استدعاء API بـ `fetch` | Tailwind، Vite، تصميم متجاوب، Figma، إمكانية الوصول | Tailwind، Plotly داخل React | جعل الأشياء واضحة وأنيقة | كثيرة |
| **C. الرسوم البيانية (Charts)** ([المهام](ar/C-charts-lenses.md)) | أي مكتبة رسوم بيانية (Plotly أو Matplotlib أو D3 أو Chart.js)، وفهم المحاور والوحدات | React، هندسة (مسافات ودوائر)، تفكير رقمي | أساسيات Plotly.js | تحويل الأرقام إلى صور تشرح الفكرة | متوسطة إلى كثيرة |
| **D. استخراج البيانات** ([المهام](ar/D-data.md)) | جداول (Excel أو Google Sheets)، قراءة أوراق علمية وPDF بالإنجليزية، دقة وانتباه للتفاصيل، تحويل الوحدات | خلفية علمية أو هندسية، Python وpandas، قراءة الرسوم | صيغة الصفوف وقواعد الاستخراج | العمل الدقيق المفصّل حيث تهم الدقة | خفيفة (غير مطلوبة) |
| **E. الذكاء الاصطناعي والاسترجاع** ([المهام](ar/E-ai-retrieval.md)) | Python وJSON واستدعاء APIs | خبرة بالـ Prompts أو LLM، Ollama أو Hugging Face، Embeddings، عقلية اختبار | أساسيات Ollama، استرجاع بسيط | جعل الذكاء الاصطناعي يعمل بشكل موثوق وآمن | كثيرة |
| **F. البحث والتوثيق والعرض والاختبار** ([المهام](ar/F-research-pitch-qa.md)) | كتابة وتحدث واضحان (عربي وإنجليزي)، تنظيم، فضول | تقديم العروض، مونتاج فيديو، شرائح أو Figma، خبرة اختبار | قراءة الأوراق البحثية، خطة الاختبار | رواية القصة، التحقق من المعلومات، اكتشاف الأخطاء | لا شيء |

### كيف تختار (5 دقائق)

1. اقرأ الجدول. ضع دائرة حول الأدوار التي تحقق فيها **كل** بنود "مطلوب".
2. إذا اخترت أكثر من دور، فاختر الذي فيه أكبر عدد من "ميزة إضافية"، أو الذي تريد أن تتعلمه.
3. إذا لم تنطبق عليك أي أدوار، فاختر D أو F. يحتاجان إلى دقة وفضول لا إلى برمجة، ويمكنك التطور لاحقًا إلى دور برمجي.
4. اكتب اختيارك الأول والثاني في مجموعة الدردشة. عند التعادل يُفضَّل من بنى شيئًا مشابهًا من قبل.
5. اكتب اسمك و**البديل (Backup)** في [../02-team-roles.md](../02-team-roles.md).

### اختبار سريع لنفسك

أجب بنعم أو لا، ثم عدّ إجابات "نعم" في كل مجموعة.

- **مجموعة A/E (الخلفية والذكاء الاصطناعي):** كتبت برنامج Python من 100 سطر أو أكثر. أعرف ما هو JSON. استخدمت API. استخدمت git.
- **مجموعة B/C (الواجهة والرسوم):** بنيت صفحة ويب فيها أزرار أو نموذج. رسمت رسمًا بيانيًا بالكود. أحب تحسين شكل الأشياء.
- **مجموعة D/F (البيانات والبحث):** أستمتع بقراءة المستندات الطويلة. ألاحظ الأخطاء الصغيرة. أستطيع شرح فكرة ببساطة أمام الناس. أحب التنظيم.

إذا كانت إجاباتك "نعم" في الغالب لمجموعة ما، فاختر دورًا من هذه المجموعة.

### إذا لم يتطابق الفريق تمامًا مع الأدوار

| الحالة | ما العمل |

| لا أحد جيد في التصميم | B ينسخ النموذج التجريبي الجاهز، فهو مصمم بالفعل |
